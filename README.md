# Codealpha-Language-translator
AI-based Language Translation Tool developed using Python, Streamlit, and Deep Translator API for translating text into multiple languages instantly.

## 📌 Project Overview
This project is a Language Translation Tool developed as part of my Artificial Intelligence Internship at CodeAlpha.

The application allows users to translate text from one language to another instantly using Google Translator API.

---

## 🚀 Features
- Translate text into multiple languages
- User-friendly interface
- Instant translation output
- Real-time language processing
- Built using Python and Streamlit

---

## 🛠️ Technologies Used
- Python
- Streamlit
- Deep Translator API

## ▶️ How to Run

### Install Required Libraries

```bash
pip install streamlit deep-translator
```

### Run The Project

```bash
streamlit run app.py
```
